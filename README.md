**🧩 Obsidian Nene 插件**
一个模块化的 Obsidian 综合增强插件，把多个第三方插件功能整合进一个插件并按模块装配，主要包含以下核心增强模块：

**🎨 主题增强**
- 新增护眼模式。

**📡 状态栏增强**
- 支持显示当前活动文件路径，点击复制（可设置复制绝对/库内路径）。
- 支持显示最后修改时间与创建时间（可设置前缀、时间格式）。
- 新增Snippets 管理按钮（CSS 片段快捷开关）。
- 支持状态栏元素管理（排序、隐藏）。

**🗂️ 标签栏增强**
- 支持滚轮循环切换，可跳过 CSS 隐藏标签/未加载插件标签。

**⚙️ 设置面板增强**
- 为「第三方插件」列表条目追加启停按钮，有设置界面的插件可点击切换设置页。为插件列表添加 data-plugin-name 属性支持自定义 CSS。
- 设置面侧边栏交互优化（🛠️开发中）
- 插件管理重做（🛠️开发中）

**🖱️ 右键菜单自定义**（将改名为UI与交互增强）
- 支持自定义管理“编辑区右键菜单”、“编辑区更多选项菜单”、“文件右键菜单”、“文件夹右键菜单”。
- 支持自定义管理“标题工具栏”、“侧边栏”（🛠️开发中）

**✍️ 编辑增强**
- 新增HTML标签自动补全：在输入 `>` 时，可自动补全对应的闭合标签（如输入 `<div>` 后自动补全 `</div>`）。
    - 自建提示框进行补全，Tab 补全、Esc 退出、不占用方向键。
    - 支持排除标签、忽略代码块/行内代码、粘贴行为不触发等。
    - 支持智能场景判断，可避免在代码块、行内代码或单标签（如 `<br>`）中误触发。
- 新增HTML标签命令
    - 跳转至匹配标签（Ctrl + M）：在成对的开始/结束标签间快速跳转。
    - 向左跳过当前标签（Ctrl + ←）：根据标签的嵌套结构，快速跳转到相邻的父级或子级标签。
    - 向右跳过当前标签（Ctrl + →）：根据标签的嵌套结构，快速跳转到相邻的父级或子级标签。
    - 同步更新匹配标签名（Ctrl + U，支持改单标签、双向同步）：修改一个标签名时，其对应的开始或结束标签会同步更新，确保标签配对正确。
- 新增状态栏开关按钮，可控制自动补全启停。

**🔗 命令 & URI 增强**

- 新增复制命令：可一键复制当前文件的库内路径、完整路径或其对应的 obsidian:// URI 链接。
- 扩展 URI 协议：增强了 obsidian://open 协议，支持通过参数精确控制笔记的打开方式：
    - method: 指定在新标签页 (tab)、新窗口 (window) 或新面板 (split) 中打开。
    - block: 打开笔记后，自动定位到指定的文本块。
    - header: 打开笔记后，自动定位到指定的标题。
- 新增 URI 协议：新增 obsidian://goto-plugin，以便快捷打进入插件市场、插件详情页、插件快捷键设置、插件设置面板。
- 新增文件速览命令创建功能，以支持通过命令打开特定文件（按文件动态注册）。

**📁 文件列表增强**
- 新增文件/文件夹置顶与隐藏，兼具面板管理。
- 新增隐藏文件的临时显隐开关。
- 新增文件/文件夹图标（🛠️开发中）

**🕸️ 关系图谱增强**
- 添加对 `<a>` 标签形式的正向链接支持

**📌 文件标记面板**（🛠️开发中）
- 侧边栏集中展示所有文件标记，按分组管理。文件右键菜单可添加/编辑/删除标记，支持分组创建、展开/折叠、一键折叠。按标记一键打开文件，改名/删除自动同步，自动清理失效标记。命令：打开文件标记面板。

##### 开发功能日志
Obsidian插件ねね，集成功能列表：
- **编辑增强**
  - ✅新增功能：HTML标签自动补全（基于第三方插件“k0src/Obsidian-Auto-Close-Tags-Plugin”与“bicarlsen/obsidian_html_tags_autocomplete”）
    - **自动补全**
        - **触发场景**（受不触发场景与补全后抑制影响）：
            - 输入`>`，当检测到左侧存在与之成对的`<`时，触发，可细分出以下两种场景：
                - 顺序输入`<div>`后光标停落于`>`右邻。
                - 先输入`<>`，通过左方向键或鼠标移动光标至`<>`内部，再输入标签名，通过左方向键或鼠标移动光标至`>`右邻。
            - 在同名成对标签内部输入同名开始标签，例如在`<div></div>`内部顺序输入`<div>`时，触发，检测逻辑如下：
                - 检测两侧成对的数量，若左侧存在落单的开始标签，则触发
            - 通过左方向键或鼠标移动光标至`>`右邻时，主动发起一次是否触发的检测。这意味着，通过方向键移动光标而退出的提示框，可通过将光标移回`>`右邻再次触发。
            - 完成补全后的触发抑制（避免死循环），可由方向键或输入可打印字符或<span style="border-bottom:1px dotted #000; cursor: pointer" title="无论鼠标击键几次，只要光标一直在原地，都不会解除抑制，只有先击键到别处，再击键返回光标落点，才可以解除抑制">鼠标改动光标位置</span>解除，解除后检验当前两侧标签是否成对，若不成对，触发；若成对，则不触发。
        - **不触发场景**：
            - 单标签无论任何行为都不触发，例如：`<hr>`或`<hr/>`、`<br>`或`<br/>`、`<img>`或`<img/>`等，单标签通过固定的标签列表识别
            - 粘贴HTML标签后，光标停于`>`右邻时不触发，该项场景受设置控制，例如：粘贴`<div>`等
            - 代码块内部的HTML标签的任何行为都不触发，包括反引号未闭合的不完整代码块内部，该项场景受设置控制
            - 行内代码块内部的HTML标签任何行为都不触发，包括反引号未闭合的不完整行内代码块内部，该项场景受设置控制
        - **注意事项**：
            - 若`>`、`<`以纯粹的比较语义出现，匹配逻辑将失效。
            - 检测左侧是否存在与之成对的`<`时，代码块或行代码内的标签的`<`是否计入受设置控制。
    - **补全提示框行为**
        - 补全提示框不占用上下左右方向键。
        - 补全提示框通过Tab键完成补全。
        - 补全提示框支持Esc键退出。
    - **补全命令**
        - **跳转至匹配标签**：光标位于`<>`内部，且该标签存在匹配标签时生效，用于跳转至匹配标签，支持在开始标签与结束标签之间来回跳转，光标始终停落于标签名的末尾，例如：`<div>`落于“v”右邻位置。默认快捷键为Ctrl + M。
            - 若不满足执行条件，或对单标签使用，则弹出Toast警告提示。
        - **向左跳过当前标签**：光标位于`<>`内部时生效，用于从当前标签跳转至其外层或左侧标签，支持跳转至单标签与双标签。
            - **跳转落点**
                - 光标的落点必为标签名右邻位置，例如：`<br><div>`从`<div>`跳转至`<br>`，`<br/><div>`从`<div>`跳转至`<br/>`，光标均落于“r”右邻位置，`<span><div>`从`<div>`跳转至`<span>`，光标落于“n”右邻位置。
            - **跳转规则**
                - 允许跳转目标与当前标签同名，例如：`<span><div><div></div></div></span>`的初始光标位于第二个`<div>`内部，则执行命令后光标跳转至第一个`<div>`，而不是`<span>`。
                - 绝不跳转至自身的匹配标签，例如：`<div></div>`的初始光标位于`</div>`内部，执行命令后不会跳转至`<div>`。
                - 优先跳转至开始标签，例如：`<span></span><div></div>`与`<span><div></div></span>`的初始光标位于`<div>`内部，则执行命令后均跳转至`<span>`，`</span><div></div>`的初始光标位于`<div>`内部，则执行命令后跳转至`</span>`。若跳转目标为单标签，则无视优先级。
                - 跳转方向必须为左，跳转距离必须最短，例如：`<span><p></p><div></div></span>`的初始光标位于`<div>`内部，则执行命令后跳转至`<p>`，而不是`<span>`。
            - **错误警告**：若当前文档只有当前标签及其匹配标签，或不满足执行条件，则弹出Toast警告提示。
            - **约束限制**：跟随设置面板的设置项约束。
            - **默认快捷键**：Ctrl + ←。
        - **向右跳过当前标签**：光标位于`<>`内部时生效，用于从当前标签跳转至其内层或右侧标签，支持跳转至单标签与双标签。
            - **跳转落点**
                - 光标的落点必为标签名右邻位置，例如：`<div><br>`从`<div>`跳转至`<br>`，`<div><br/>`从`<div>`跳转至`<br/>`，光标均落于“r”右邻位置，`<div><span>`从`<div>`跳转至`<span>`，光标落于“n”右邻位置。
            - **跳转规则**
                - 允许跳转目标与当前标签同名，例如：`<span><div><div></div></div></span>`的初始光标位于第二个`<div>`内部，则执行命令后光标跳转至第二个`</div>`，而不是`</span>`。
                - 绝不跳转至自身的匹配标签，例如：`<div></div>`的初始光标位于`<div>`内部，执行命令后不会跳转至`</div>`。
                - 优先跳转至开始标签，例如：`<span></span><div></div>`的初始光标位于`<span>`内部，则执行命令后跳转至`<div>`，`<div><span></span></div>`的初始光标位于`<span>`内部，则执行命令后跳转至`</div>`，`<span><div></div></span><p></p>`的初始光标位于`<div>`内部，则执行命令后跳转至`<p>`，而不是`</span>`。若跳转目标为单标签，则无视优先级。
                - 跳转方向必须为右，跳转距离必须最短，例如：`<span><p></p><div></div></span>`的初始光标位于`<p>`内部，则执行命令后跳转至`<div>`，而不是`<span>`。
            - **错误警告**：若当前文档只有当前标签及其匹配标签，或不满足执行条件，则弹出Toast警告提示。
            - **约束限制**：跟随设置面板的设置项约束。
            - **默认快捷键**：Ctrl + →
        - **同步更新匹配标签**：光标位于`<>`内部时生效，且该标签存在匹配标签时生效，用于同步更新匹配标签的标签名，且更新前后光标位置保持不变。
            - **交互逻辑**：执行命令后，在光标右下角弹出编辑输入框并聚焦，用户可以选择输入新的标签名后回车，也可以选择通过Esc键或鼠标点击其它区域退出。
            - **执行逻辑**
                - 编辑输入框的内容默认为当前标签名，且处于选中状态，若当前标签为结束标签，则当前标签名不包含“/”。
                - 编辑输入框仅支持输入大小写字母与“/”，且大小写不敏感，确认统一转换为小写字母。若输入非法字符，则编辑输入框下出现红色小字提示，并禁用Enter键。
                - 编辑输入框在输入过程中不会因输入合法字符而失去焦点。
                - 编辑输入框仅允许“/”最多出现一次，且必须位于结尾，若非法，则编辑输入框下出现红色小字提示，并禁用Enter键。
                - 当新标签名以单个“/”结尾时，回车将触发二次确认，是否将当前标签更新为单标签。
                - 用户回车确认新的标签名后，同步更新当前标签的开始标签与结束标签的标签名。若更新为单标签，则以光标初始所在的标签为基准，删除其匹配标签并更新当前标签的标签名，例如：`<div>文本</div>`的初始光标位于`<div>`内部，则执行命令后删除`</div>`，`<div>`更新为单标签。

                - 若更新前后标签名不变，则Toast提示，不进行更新操作。
